# 排序研习室

双击 `sorting-review.html` 即可离线使用，无需安装。

- 八种排序：直接插入、折半插入、希尔、冒泡、快速、堆、归并、基数。
- 单步、回退、变速播放、进度拖动；当前操作同步高亮 C++ 代码。
- 堆的完全二叉树、归并辅助数组、基数桶，以及插入时的暂存元素。
- 可输入 3–20 个 0–999 的整数，也可切换有序、逆序、随机和重复数据。
- 每个元素带原始序号，可观察相等元素的相对次序是否保持。
- 复制或下载 C++17 示例，包含当前数据和 main()。
- 八法速查、16 道自测、回忆题、60 分钟复习计划及本地掌握标记。

键盘：左右方向键单步；Home 回到开始，End 跳到结果。焦点不在输入或按钮上时，空格播放 / 暂停。

进度只保存在当前浏览器。换浏览器或清理本地存储后不会同步。

本页使用下标从 0 开始的升序版本。快排使用末元素作轴的 Lomuto 划分（严格小于轴的元素放左侧）；希尔采用折半增量；基数固定完成个位、十位、百位三轮。速查备注解释了实现差异，复习时请结合课堂使用的版本。
